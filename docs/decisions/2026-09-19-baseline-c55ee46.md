# Baseline sync: Upstream c55ee46 (2026-09-18)

The first entry. FIKS started from the 25 skills installed with `npx skills` on 2026-09-19. Before restructuring, each was compared with a fresh clone of Upstream at `c55ee46`: all 25 were byte-identical, so that commit is the baseline. The Mirror holds Upstream at that commit; `skills/` holds the FIKS versions.
